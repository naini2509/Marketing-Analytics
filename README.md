📊 **Marketing Analytics (Power BI, SQL, Python)**
________________________________________
📖 **Project Overview**

This project analyzes the marketing performance of ShopEasy, an online retail business facing reduced customer engagement and declining conversion rates despite increased marketing spend. Using SQL, Python, and Power BI, the project uncovers insights into campaign effectiveness, customer behavior, product performance, and sentiment trends to recommend actionable improvements.
________________________________________
🛠️ **Technologies Used**

•	SQL: Data cleaning, enrichment, joins, categorization, and CTEs

•	Python (Pandas, NLTK): Sentiment analysis on customer reviews

•	Power BI: Dashboard development, DAX calculations, time-series, and advanced visualizations
________________________________________
🌟 **What Makes This Project Unique?**

It combines structured data analysis (SQL, Power BI) with unstructured text insights (Python sentiment analysis), merging quantitative performance metrics with qualitative customer feedback to create a 360° view of marketing effectiveness.
________________________________________
🔑 **Objectives**

•	Clean and enrich marketing, customer, and product data

•	Analyze conversion trends, customer engagement, and sentiment

•	Identify product categories and content types driving performance

•	Provide actionable insights to optimize marketing strategies
________________________________________
🎯 **Primary Goals**

•	Boost conversion rates by identifying drop-off points in the funnel

•	Increase customer engagement by refining content and channel strategies

•	Improve customer satisfaction by addressing key pain points surfaced in reviews

•	Align marketing efforts to seasonal and product-specific trends
________________________________________
💼 **Business Problems Solved**

•	Why are conversion rates declining despite higher marketing spend?

•	Which products, campaigns, or content types are most effective?

•	How do customer perceptions (ratings, reviews) align with actual performance?

•	What data-driven steps can improve ROI and customer loyalty?
________________________________________
📊 **Dataset Details**

•	dim_customers + dim_geography → enriched customer profiles

•	products → categorized by price tiers

•	customer_reviews → sentiment-scored and categorized

•	engagement_data → cleaned, normalized views, clicks, likes

•	customer_journey → deduplicated and aggregated

•	Calendar table (Power BI) → full time-series context (2023–2025)
________________________________________
🏗️ **Steps Followed**

1. Wrote SQL queries to clean, join, enrich, and categorize datasets
   
2. Built Python scripts to run sentiment analysis (VADER) on customer reviews
 
3. Created a Power BI calendar table for time-based calculations
 
4. Developed Power BI visuals: time trends, engagement funnels, sentiment distribution
 
5. Highlighted seasonal and product-specific insights with DAX measures
 
6. Formulated recommendations to address underperforming areas
